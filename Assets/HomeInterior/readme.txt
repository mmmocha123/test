BLENDER

Use real-time AO for better appearance. The Blender file has real-time AO already applied. No texture filtering (nearest neighbor) recommended.


UNITY 6

The materials are made for URP. If you're using the built-in renderer or HDRP, you must convert the materials. Only the clothes materials uses URP shader graph to give a color tint.

It's recommended to use SSAO. See the included jpg file for Unity AO settings.
